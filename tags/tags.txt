# IELTS Content Tag Vocabulary — v2 3-Layer System
# ══════════════════════════════════════════════════════════════════
# 5 L1 → 15 L2 → 30 L3
# Layer 1  — 5 fixed category tags (exactly one per topic)
# Layer 2  — thematic cluster tags (domain / sub-domain)
# Layer 3  — specific / concrete tags (narrow concept under an L2)
# Qualifiers — describe tone/quality; stored separately in qualifier_tags
# ══════════════════════════════════════════════════════════════════

## ── LAYER 1 — fixed categories ──────────────────────────────────
people
place
object
experience/activity
abstract_concepts

## ── LAYER 2 & 3 — by L1 parent ──────────────────────────────────

# [people] — 3 L2
professions          # doctors, actors, athletes, leaders, famous persons
close_bonds          # family, friends, colleagues, neighbours
general              # society, citizens, crowd, generation, strangers

# [place] — 2 L2
outdoor              # nature, scenery, parks, mountains, cities, countries
indoor               # houses, buildings, museums, libraries, shops, schools

# [object] — 2 L2, 4 L3
tangible             # food, clothes, shoes, gifts, toys, cameras, instruments, plants
intangible           # non-physical objects
# L3 under intangible:
artwork              # [intangible] books, music, movies, paintings, photographs
technology           # [intangible] apps, computers, phones, internet, social media
money                # [intangible] cash, fees, salary, prices, spending
media                # [intangible] advertisements, news, TV programs, reports

# [experience/activity] — 4 L2, 7 L3
work                 # jobs, careers, business, companies, employment
study                # courses, subjects, education, language learning, exams
leisure              # free time activities
# L3 under leisure:
exercise             # [leisure] sports, games, walking, cycling, team activities
shopping             # [leisure] buying, stores, malls, markets
cooking              # [leisure] food prep, meals, restaurants, eating out
traveling            # [leisure] journeys, trips, visits, tourism, transport
creative             # [leisure] drawing, painting, photography, crafting
reading              # [leisure] books, articles, e-books, libraries (leisure context)
entertainment        # [leisure] movies, music, concerts, shows, games (consuming)
routines             # daily habits, chores, morning/bedtime, schedule

# [abstract_concepts] — 6 L2, 19 L3
communication        # advice, arguing, chatting, speaking, apologizing
emotion              # feelings and emotional states
# L3 under emotion:
pride                # [emotion] proud, accomplishment, achievement
happiness            # [emotion] joy, smiling, enjoyment, fun
fear                 # [emotion] worry, anxiety, danger, reluctance
anger                # [emotion] arguing, frustration, conflict
attachment           # [emotion] missing, nostalgia, sentimental, keeping old things
regret               # [emotion] sorry, apologize, mistake
patience             # [emotion] waiting, tolerance, delayed gratification
personal_traits      # personal attributes, abilities, moral qualities
# L3 under personal_traits:
creativity           # [personal_traits] artistic ability, innovation, imagination
problem-solving      # [personal_traits] finding solutions, fixing issues
craftsmanship        # [personal_traits] making by hand, quality of handmade work
responsibility       # [personal_traits] duty, accountability, ownership
honesty              # [personal_traits] truthfulness, sincerity, authenticity
values               # social/cultural norms and systems
# L3 under values:
policy               # [values] laws, government rules, regulations, bans
environment          # [values] conservation, pollution, green choices, wildlife
economics            # [values] spending, consumption, economic growth
fairness             # [values] equality, justice, access, equity
personal_growth      # development and self-improvement
# L3 under personal_growth:
learning             # [personal_growth] education, acquiring knowledge
self-improvement     # [personal_growth] getting better at something, practice
adaptation           # [personal_growth] adjusting to change, coping
goal-setting         # [personal_growth] plans, ambitions, future aspirations
decision             # [personal_growth] choices, weighing options, judgement
influence            # persuasion, inspiration, encouragement, impact
time                 # life stages, generations, childhood, past vs present

## ── QUALIFIERS — stored in qualifier_tags, not content_tags ─────
memorable            # special, noteworthy, stands out in memory
sentimental          # emotionally attached, personally meaningful
peaceful             # quiet, calm, tranquil
useful               # helpful, practical, beneficial
interesting          # unusual, thought-provoking, captured attention
